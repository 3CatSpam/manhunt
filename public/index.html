Règles du jeu
  • Les joueurs sont répartis au hasard en hiders et hunters (moitié-moitié).
  • Les hiders partent se cacher : les hunters attendent la fin de l'avance (10 min par défaut).
  • Ensuite, la position de chaque hider est pingée toutes les 5 minutes : les hunters voient le dernier ping sur la carte.
  • Restez dans la zone de jeu. Un hider attrapé le signale dans l'appli.
  • La manche finit quand tous les hiders sont attrapés. Puis les rôles s'inversent.
